# Claude作業中グローエフェクト

Claude Codeに指示を出してから応答が終わるまでの間、画面の縁がうっすら赤く光って
脈動（パルス）するオーバーレイを表示するツールです。

「今Claudeが作業中」であることを画面の外側からも分かりやすくするための、見た目だけの
インジケーターです。マウス・キーボードの操作はそのままブロックされずに使えます
（クリックスルー）。

## できること・できないこと

- できること: Claude Codeが処理している間（指示を送ってから、応答が止まるまで）、
  画面の縁を赤くうっすら光らせる
- できないこと: これはあくまで「見た目の通知」です。Claude自身がマウスやキーボードを
  操作する機能（PCを自動操作する機能）ではありません

## インストール方法

1. `install.bat` をダブルクリックする
2. 完了画面が出たら、開いているClaude Codeのウィンドウで一度 `/hooks` と入力する
   （設定を再読み込みするため）。新しく `claude` を起動する場合は不要です。

これで、次にClaude Codeに指示を送ると画面の縁が赤く光り、応答が終わると消えます。

## アンインストール方法

`uninstall.bat` をダブルクリックしてください。設定ファイル（`settings.json`）は
変更前にバックアップが自動で作られます。

## 仕組み

- `install.bat` が以下を行います
  - オーバーレイ表示用のPowerShellスクリプトを `%USERPROFILE%\.claude\glow\` にコピー
  - `%USERPROFILE%\.claude\settings.json` に以下の2つのフックを追加
    - `UserPromptSubmit`（指示を送った時）→ オーバーレイ表示を開始
    - `Stop`（Claudeの応答が止まった時）→ オーバーレイを非表示
- 既存の `settings.json` の内容は壊さず、フックだけ追加します（変更前に自動バックアップ）

## 見た目を調整したい場合

`%USERPROFILE%\.claude\glow\glow.ps1` を直接編集してください。

- `$borderWidth`: 縁の太さ（ピクセル）
- `[System.Drawing.Color]::Red`: 縁の色
- `$timer.Interval`: アニメーションの更新間隔（ミリ秒）
- `0.20 + 0.20 * [Math]::Sin($script:phase)`: 明るさの変化範囲（脈動の強さ）

編集後は、次にオーバーレイが表示されるタイミングから反映されます
（再インストール不要）。
